# Bankin95 (Savings 95)

Мобильное приложение для Android и iPhone в ретро-стиле Windows 95. Считает, сколько денег можно безопасно отложить в месяц:

```
доход − обязательные платежи − еда на месяц − резерв = безопасный максимум
```

Еда считается из блюд, которые пользователь выбрал свайпом, с учётом нормы калорий, аллергенов и диеты.

Дизайн: Figma-файл `app` (страницы Cover и Mockups).

## Стек

- Expo SDK 58, React Native, TypeScript
- Expo Router (файловая навигация в `src/app/`)
- Шрифты Press Start 2P и VT323 (Google Fonts, лицензия OFL)
- Данные хранятся локально на устройстве (AsyncStorage)

## Запуск

```bash
npm install
npx expo start
```

Отсканируйте QR-код приложением Expo Go (Android) или камерой (iPhone).

Проверки перед коммитом:

```bash
npx tsc --noEmit
npx expo lint
```

## Структура

```
src/
  app/                 экраны (Expo Router)
    setup/             онбординг: язык и валюта, цель
    calc/              расчёт месяца: доход → платежи → калории → аллергены →
                       свайп блюд → план еды → продукты → расчёт → итог →
                       разбивка → подтверждение → отложено
    menu.tsx, mealplan.tsx, history.tsx, goals.tsx, settings.tsx
  components/          Window (окно Win95), кнопки, поля, клавиатура, плитка блюда
  domain/              расчёты (калории, план, продукты, итог), деньги, рецепты
  i18n/                тексты EN / RU
  state/               хранилище состояния и сохранение
  theme/               цвета (светлая и тёмная тема), шрифты
```

## Что работает

- Онбординг: язык и валюта, цель (пример или своя)
- Ввод дохода (до 7 цифр), платежи с удалением и отменой
- Норма калорий по формуле Миффлина–Сан Жеора, цель «похудеть / держать / набрать»
- Аллергены, диета, «не люблю», поиск и свои аллергены
- Свайп карточек блюд: вправо — нравится, влево — никогда, вверх — пропуск
- План еды на месяц с порциями, список продуктов, итог, состояние «не хватает денег»
- Подтверждение суммы, прогресс к цели, история, план питания на неделю
- Светлая и тёмная тема, EN / RU, USD / RUB

## Ограничения (демо)

- Цены продуктов — демо-данные; поиск магазинов рядом и геолокация не подключены.
- Вместо фото блюд — пиксельные плитки (фото в макете — заглушки с лицензией CC, их нужно заменить или указать авторов).
- Напоминания пока только переключатель, без push-уведомлений.
